一个面向 SillyTavern 的多功能扩展，包含剧情总结/记忆系统、变量系统、任务与多种面板能力。集成了画图、流式生成、模板编辑、调试面板等组件，适合用于复杂玩法与长期剧情记录。

## 本改版相对原版改了什么（Memory+ 1）

全部改动都是在原版基础上的追加与增强，没有删减原有能力：

1. **事件可在任意位置插入与排序**：剧情时间线支持「在前插入 / 在后插入 / 上移 / 下移 / 搜索 / 撤销结构操作」，排序写入独立 `sortOrder`，不改动事件原文楼层。
2. **人物基础档案（固定人设）**：新增独立面板，字段默认锁定，AI 更新必须携带证据，冲突进入「待审核」，避免每次总结把人物性格刷成新的导致 OOC；原「人物档案」改名「关系与成长」，原功能保留。
3. **可调注入位置**：面板顶部「注入位置」可在 自动 / 手动固定深度 / 强制置于聊天末尾 之间切换，并为人物质稿提供独立字符预算。

改版版本标识 `3.1.2-memory.2`（见 `manifest.json`，面板副标题显示 `Memory+ 2`）。安装、备份与回退说明见 `总结增强版-安装说明.md`，验证记录见 `总结增强版-验证记录.md`。

### 修复记录

- `3.1.2-memory.2`：修复在 HTTP 明文页面（非安全上下文，浏览器不提供 `crypto.randomUUID`）下「＋ 新建人物 / 补齐主要人物空白档案」点击无反应的问题；同时让这两个按钮在失败时显示原因、在无可用人物名时给出提示，不再静默无反应。
